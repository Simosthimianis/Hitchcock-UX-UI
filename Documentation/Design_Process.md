# Design Process

## 1. Research Before UI

The project intentionally began with UX research rather than visual styling. Competitor analysis and participant feedback were used to identify opportunities around content depth, navigation and clarity of purpose.

## 2. Moodboard

The moodboard combined imagery associated with films such as *Vertigo*, *Psycho*, *The Birds* and *Rear Window* to define a noir / suspense direction.

Primary qualities:

- noir,
- psychological tension,
- mystery,
- archival atmosphere,
- classic cinema editorial design.

## 3. Wireframes

Low-fidelity wireframes were created to establish:

- global navigation,
- filmography structure,
- biography timeline,
- gallery composition,
- content blocks and page hierarchy.

## 4. Visual Direction Exploration

Two UI directions were explored.

### Direction A - Noir / Dark

A near-black interface with restrained burgundy accents. This direction was chosen for the final prototype because it more strongly reflected suspense, mystery and Hitchcock's cinematic identity.

### Direction B - Poster-Inspired Color

A brighter palette using colors inspired by classic film posters. This direction was visually expressive but less aligned with the intended archive/noir experience.

## 5. High-Fidelity Prototype

The final prototype developed six primary pages:

- Home,
- Filmography,
- Gallery,
- Biography,
- Director's Cut,
- Contact.

The design combines visual storytelling, chronological structure, editorial text and image-heavy discovery.
